# Documentation Topic List — Jobs, Marketing & Freelance (All Roads Lead to "Make Real Money")

> A working topic bank, not finished docs. Every topic below is picked because it has real search demand _and_ a clear money-making payoff for the reader — no filler "what is freelancing" explainer content. Each one names the specific way it makes the reader money, so the whole set reads as one connected system rather than 40 unrelated blog ideas.

---

## The throughline (read this first)

Three categories, one funnel:

**Jobs** (stable income) → **Freelance/Business** (income you control) → **Marketing** (income you can scale).

A reader lands on a Jobs doc because they need income now, gets shown the Freelance path once they have a skill, and gets shown Marketing once they have clients and need to grow past their own hours. That's the throughline every topic below should serve — nothing "purely informational" with no money angle.

## How to use this list

- Treat each row as a doc waiting to be written — same depth/format as the two already made (research-backed, source-linked, developer/business-friendly, not written for a general audience).
- Sequence matters: publish **Jobs** topics first (broadest search demand, easiest entry point), then **Freelance** (converts job-seekers into Frenzz's actual audience — solo founders/agencies), then **Marketing** (retains and grows people already sold on the freelance path).
- Every doc should end with a clear "next step" pointing to the next topic in the funnel — that's what makes 30 separate docs behave like one system instead of a scattered blog.
