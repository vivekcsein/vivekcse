Create a **premium, futuristic, highly interactive full-stack developer portfolio website design** for a developer named **Vivek**, handle **@vivekcsein**.

The website should feel like the portfolio of a **top-tier software engineer, product engineer, and creative technologist**, not a generic developer template. The visual language should communicate: **advanced engineering, scalability, architecture, 3D, AI-era development, performance, security, and exceptional UI craftsmanship**.

### Overall Art Direction

Design a **long-form 1920px-wide desktop portfolio landing page** with a sophisticated dark interface.

Use:

- Deep near-black / charcoal backgrounds
- Zinc/slate surfaces
- White and muted-gray typography
- Violet/indigo primary accent
- Subtle electric-blue secondary glow
- Thin borders
- Soft shadows
- Controlled glassmorphism
- Subtle gradients
- Fine grid patterns
- Atmospheric particles
- Soft radial lighting
- High-quality 3D renders
- Strong depth and layering
- Premium SaaS/product-design aesthetics
- Shadcn/ui-inspired component language
- Excellent WCAG-oriented readability
- Large, confident typography
- Generous whitespace
- Precise alignment and spacing

Avoid excessive neon, cyberpunk clichés, rainbow gradients, noisy backgrounds, excessive glassmorphism, tiny text, or clutter.

The design should look **expensive, minimal, technically sophisticated, and production-ready**.
